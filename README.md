# Base simulada – Six Sigma (retrabalho)

**Atenção: todos os dados são fictícios**, criados para fins acadêmicos.

## Conteúdo
- `Base_Simulada_Six_Sigma.xlsx`: abas Base_Pecas, Resumo_Mensal, Analise_Fatores, Parametros e Dicionario.
- Período: janeiro a junho de 2026 | 22.965 peças (uma linha por peça).
- Semente aleatória da simulação: 42.

## Indicadores
- IR: peças que necessitaram de retrabalho ÷ peças produzidas
- ID: peças descartadas ÷ peças produzidas
- HR: soma dos minutos de retrabalho ÷ 60
- AP: peças aprovadas sem retrabalho ÷ peças produzidas

## Observações
- Se enviar o CSV: separador `;`, decimal com vírgula, UTF-8.
